# 配套示例

本目录保存与书稿配套的可运行示例。

## dsh-learning-coach

[`dsh-learning-coach`](dsh-learning-coach/) 是贯穿全书的持续学习教练插件，展示 DSH 的插件装配、系统提示、工具、命令、状态持久化和会话事件监听。

```bash
cd demo/dsh-learning-coach
npm ci
npm run check
npm run build
```

安装到 DSH Profile 和端到端验证方法见其 [README](dsh-learning-coach/README.md) 与 [MVP 使用说明](dsh-learning-coach/MVP_USAGE.md)。
